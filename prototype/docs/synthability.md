# 合成性（Synthability）评估方案 · v0.1

> 状态：**待实现**。这份文档只定义口径，不改代码。
> 前提（用户已定）：组装方式做成可切换参数、默认最严（Golden Gate）；供应商取 Twist / IDT 中更严的一侧；现阶段**没有可校准的历史数据**，所以只做可解释的规则分级，界面明确标注「未校准」。

---

## 1. 定义与边界

**合成性** = 在给定「合成商 + 组装方式」下，一个**被合成的单元**能被正确合成、正确组装、并在测序里辨认出预期变体的置信度。

- 评价单位不是「变异密码子 ±4 nt」，而是 **oligo**（60–80 nt）与它所在的 **组装片段**。
- 不预测表达量、折叠、功能——那是 DMS 的下游分析。
- 现在代码里那个 `99 − |GC−0.52|×90 − …` 的 0–100 分**作废**：颗粒度错、权重无来源、给了假精度。

## 2. 三级映射

```
variant  ──►  oligo（真正被合成的序列）
             └─►  assembly（Golden Gate 的插入片段 / Gibson 的重叠区 / 直接合成的 dsDNA）
```

- 用户操作的对象是 **variant**（表格、抽屉、批量），但所有证据算在 **oligo / assembly** 上。
- 一个 oligo 承载 1 个位点的 19 个变体时，19 个变体共享同一条 oligo 的合成性判断，只在「密码子本身」这一项上分叉。

## 3. L1 硬闸门（规则，逐条可解释）

每条规则都记录：`规则 ID · 实测值 · 阈值 · 判定 · 依据版本`。界面上的「为什么」直接引用这些字段，不写形容词。

| ID | 检查 | 保守初值 | 动作 | 备注 |
| --- | --- | --- | --- | --- |
| R-01 | oligo 整体 GC | 0.30–0.70 通过；<0.20 或 >0.80 剔除；其余待复核 | 待复核 / 剔除 | 供应商公开指引普遍要求避开极值，初值取偏严一侧 |
| R-02 | 最长同聚物 | ≥6 待复核；≥8 剔除 | 待复核 / 剔除 | A/T 与 G/C 分开统计，poly-G 更严（≥5 即待复核） |
| R-03 | 直接重复 | 同一 8 nt 出现 2 次待复核；≥12 nt 重复剔除 | 待复核 / 剔除 | 重复是阵列合成的主要失败源 |
| R-04 | 反向重复 / 发夹 | 茎 ≥6 bp 或 ΔG < −9 kcal/mol 待复核；ΔG < −12 剔除 | 待复核 / 剔除 | ΔG 由 L2 提供 |
| R-05 | 限制性位点 | Golden Gate 模式下 BsaI / BsmBI / BbsI 及反向互补 → **剔除** | 剔除 | 随组装方式启用/关闭，见第 5 节 |
| R-06 | 组装 overhang 唯一性 | 4 nt overhang 在片段集合内不唯一、或与载体已用 overhang 相同、或为回文 → **剔除** | 剔除 | Golden Gate 专有；这是会整批失败的阻断项 |
| R-07 | 混合碱基位点 | NNS 位点实际混碱比例偏离 25% 超过 ±10% → 待复核 | 待复核 | 部分供应商对简并位点另有规格 |
| R-08 | 端点 | 5′ 端为 G、或末端 3 nt GC = 0 或 = 3 → 待复核 | 待复核 | 影响连接与延伸效率 |
| R-09 | 长度 | 超过合成商上限（片段长度 / 池复杂度） | 阻断 | 按供应商规格书取值 |
| R-10 | 与固定元件冲突 | 命中引物、接头、条形码区、已知重复元件 | 待复核 | 需要项目的元件表 |

> **阈值来源说明（本次核查后的结论，见 3.5）：上表是自建的保守 v0，不能标称「某家的规则」。** 实现时用 `ruleSet{ vendor, version, rules[], sources[] }`，每条规则带 `source`（URL + 抓取日期 + 原文摘要）或 `unverified` 标记；接供应商规格书时逐条替换，不改代码。

## 3.5 「合成商公开的序列复杂度规则」到底公开到什么程度（2026-10 核查）

结论：**不存在一份可直接抄的完整规则表。** 公开的是 guidance，不是算法。

| 渠道 | 有什么 | 能不能当规则源 |
| --- | --- | --- |
| Twist [Manufacturability Analyzer](https://www.twistbioscience.com/products/genes/manufacturability-analyzer) | 免费工具，输入序列给可制造性判断；评分模型与阈值**未公开** | 不能拿规则，能当**黑盒 oracle** 做对照 |
| Twist [Gene Synthesis FAQ](https://www.twistbioscience.com/faq/gene-synthesis) | 有 "sequence acceptance criteria" 条目，正文以产品说明为主，细节需规格书 | 只能当线索 |
| Twist [Multiplexed Gene Fragments 设计指南 PDF](https://www.twistbioscience.com/de/ja/content/dam/twistbioscience/resources/2024-05/MultiplexedGeneFragmentsExternalDesign_May2024Guidelines.pdf) | 有专门的设计指南（本次抓取被工具拦下 application/pdf，未读到正文） | 需要下载后人工摘录 |
| [OligoPool.com 设计检查页](https://oligopool.com/oligo-pools/design-rules) | **明确说：没有 pool 级通用 GC 接受区间；ΔG 不是通用阈值；长度约束取决于应用和供应商**；并建议按其当前规格书确认 | 反向证据：说明「通用规则表」不存在 |
| GenScript [GenTitan Oligo Pool User Guide](https://www.genscript.com/gsfiles/techfiles/Protocol_GenTitan_Oligo_Pool_User_Guide_Amplification_Guidelines_2024.pdf) | 有官方 user guide（PDF 未读正文） | 需下载后摘录 |

因此方案调整为三步，不假装有官方规则：

1. **自建 v0 + 来源标注**：能确认的条目抄进 `sources[]`（URL + 日期 + 原文摘要），确认不了的一律 `unverified`；界面显示「自建保守规则 v0 · 未校准 · 非供应商规格」。
2. **黑盒对照**：把我们的 A/B/C 与供应商免费分析器的判定做一致性检验（κ），差异条目逐条写注记。这比抄一份来路不明的阈值表可靠。
3. **官方规格书**：向销售索取 spec sheet / 下单系统的报错语料（提交被拒时的原因文字就是最真实的规则），再替换参数。

## 4. L2 结构软评分（可复现的物理量，不是权重）

用最近邻热力学算，不发明系数：

- **ΔH / ΔS / ΔG°37**：SantaLucia 1998 unified 参数（10 种碱基对 + 8 种错配可选）
- **盐浓度修正**：SantaLucia 1998（或 Owczarzy 2004，二选一并写死版本）
- **发夹**：环长度相关的 Jacobson–Stockmayer 起始项 + 末端 AT 罚分
- **二聚**：自身二聚（同一条 oligo 的两段互补）、池内异二聚（只在 k-mer 预筛出的候选对上做精确计算，避免 O(n²) 爆炸）

输出三个物理量：`hairpinΔG`、`selfDimerΔG`、`tm`。分级仍由 L1/L2 联合决定，**不出小数分**。

## 5. 组装方式作为参数（你说都想要）

| 规则 | Golden Gate（默认） | Gibson / 同源重组 | 直接合成 dsDNA |
| --- | --- | --- | --- |
| R-05 酶切位点 | 启用（BsaI/BsmBI/BbsI） | 关闭 | 关闭 |
| R-06 overhang 唯一性 | 启用 | 换成「20–40 nt 重叠区唯一 + Tm 匹配 ±2 °C」 | 不适用 |
| R-03 重复 | 启用 | 启用 | 启用，阈值放宽（长片段重复更常见） |
| R-07 混碱位点 | 启用 | 启用 | 不适用 |
| 长度上限 | oligo ≤ 供应商上限 | 片段重叠区长 20–40 nt | 整段 500–3000 nt |

切换组装方式只替换规则子集与阈值，评价单位与界面不变。

## 6. 分级与呈现（界面怎么改，实施时照此做）

- **表格**：`合成性` 列显示 `A / B / C`，不显示 0–100。
  - A = 全部规则通过；B = 命中待复核项；C = 命中任一剔除项。
- **抽屉**：`合成性 B` 下面直接列依据，例如
  `R-02 最长同聚物 7 ≥ 6（待复核）`、`R-04 发夹 ΔG −10.3 < −9（待复核）`，
  再给一句修正建议（换同义密码子 / 换同义但避开 poly-G / 调整 overhang）。
- **工作台告警**：按规则族聚合计数（酶切位点 12 / GC 29 / 重复 8 / 发夹 4），不再是笼统的「待复核 304」。
- **导出**：CSV 增加 `synth_grade, block_rule_ids, gc, max_homopolymer, hairpin_dg`。
- **版本标记**：数字带或页脚出现 `规则版 v0 · 未校准`，点击可看规则表与阈值来源。

## 7. 数据模型（实现时新增，不动现有字段）

```
oligo { id, seq, length, variantIds[], gc, maxHomopolymer, repeats[], hairpinDg, tm }
assembly { id, type: 'gg' | 'gibson' | 'dsdna', overhangs[], junctions[] }
ruleSet { vendor: 'twist|idt|strict', version, rules[{ id, param, threshold, action, source }] }
verdict { variantId, grade: 'A|B|C', hits[{ ruleId, measured, threshold, action }] }
```

`verdict.hits` 是唯一的展示来源——任何「为什么」都必须能指到一个 hit。

## 8. 校准路径（现在不做，先把口子留好）

1. 现有阈值一律标 `v0 未校准`。
2. 有数据后：按规则族算每个 hit 的失败率提升（有该 hit 的失败率 / 无该 hit 的失败率）。
3. 特征固定为可解释量：GC 偏离、最大同聚物长度、最长重复、hairpinΔG、异二聚数。
4. 用 logistic 回归校准概率；阈值按「允许 X% 失败率」反解，而不是拍一个 80 分。
5. 最小样本：每个规则族 ≥ 50 个失败案例，否则只更新阈值不动权重。

## 10. 已知风险与取舍

- 阈值是公开指引的保守值，不是供应商模型；因此界面必须标「未校准」，别让研究者当成承诺。
- 热力学只对单链/简单二级结构可靠；长重复、多分支结构会低估风险，靠 L1 的重复规则兜底。
- 池内异二聚在 96k 条时是瓶颈，必须 k-mer 预筛，不能全配对。
- 规则多容易变成「全红」：先按动作分档（阻断 / 待复核），阻断项不超过 3 类，否则用户会整体忽略告警。

## 11. 需要你补充才能实现的输入

1. 供应商规格书 PDF（长度/池上限、混碱规格、验收标准）——用于替换 R-01/R-02/R-07/R-09 的初值，并把 `unverified` 逐条转正。
2. 组装方式的默认值与 overhang 规划规则（GG 用几个片段、载体已用 overhang 列表）。

4. 有历史失败的位点或订单（哪怕二十条），先让校准步骤有东西可对。
