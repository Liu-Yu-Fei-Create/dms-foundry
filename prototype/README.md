# DMS Foundry · 深度突变扫描（DMS）序列文库设计

从父序列起，把一次深度突变扫描设计到可以下单。视觉身份是**严格黑白**——零彩色、零圆角、零阴影；状态只靠形状、字重、灰阶和删除线区分，**下划线只留给链接**。

## 打开

直接双击 `index.html`（普通 `<script>`，不需要构建工具，也不需要起服务）。设计改动与草稿存在浏览器 `localStorage`。回到初始状态：地址后加 `?reset=1`。目标视口 1440×900（桌面专业工具，未做移动端）。

## 四个页面

| 路由 | 页面 | 做什么 |
| --- | --- | --- |
| `#/` | 工作台 | 三件待办（第一件挡下单）+ 六个文库索引 + 最近操作 |
| `#/lib/tem1-nns` | 结果详情 | 变体表、状态筛选、行抽屉、单条/批量剔除、导出 |
| `#/lib/tem1-nns/warn` | 同上，直接落在待复核 | 工作台「去处理」的落地页 |
| `#/new` | 新建文库 | 四步向导，费用实时拆到三行，草稿自动保存 |
| `#/history` | 历史 | 版本、订单、校验记录 |

## 下单口径（重要）

**只有「可合成」的变体进订单。** 顶栏的 `下单 4,640 条` 与数字带的「预估费用（按入单）」都按可合成数量算；待复核 304 与已剔除 53 明确标为「不入单」，切换筛选不会改变这个数字。

## 数据与算法（不是编的）

- 序列：UniProt **P62593（TEM-1）** 去 23 aa 信号肽的成熟蛋白，**263 aa / 789 nt**。
- 按 E. coli 偏好密码子回译，每位点生成另外 **19** 个替换 → **4,997** 个变体。
- 每个变体现场计算：变异密码子 ±4 nt 上下文（末端不足时标注「侧翼不足」）、GC、最长同聚物、限制性位点（BsaI / BsmBI / BbsI 及反向互补）。
- 状态规则（`data.js`，可改）：已剔除 = GC ≥ 0.84 或 ≤ 0.12、同聚物 ≥ 7、命中酶切位点；待复核 = GC > 0.76 或 < 0.26、同聚物 = 6、克隆位点序列；其余可合成。
- 当前：**4,640 可合成 / 304 待复核 / 53 已剔除**，受影响位点 23 个，订单估算 **¥17,304**。
- 费用：池 `位点 × ¥26` + 克隆 `变体 × ¥1.55` + 测序 `变体 × 深度 × 150 / 1e6 × ¥0.042/千读`。

## 交互

- 顶栏切换视图，页面 190ms 淡入位移。
- 结果页：页签筛选；行首复选框、表头全选当前页；选中后工具栏换成「已选 n 条 · 标记剔除 / 导出所选 / 清除」，批量剔除会报「影响 n 个位点」并可撤销。
- 行抽屉：230ms 滑入并**让出工作面**（不遮状态列、无遮罩），给出结论句、复核原因、真实上下文、合成性阈值；`↑↓` 或「下一条」连续复核，`Esc` 关闭。
- 单条动作：抽屉里「确认进池 / 剔除」，行尾常显「剔除 / 恢复」。
- 反馈走页面底部状态行（不再浮层压住表格），6 秒内在同处撤销。
- 导出 CSV：按当前筛选或所选导出真实数据（UTF-8 BOM）。
- 键盘可达；动效尊重 `prefers-reduced-motion`。

## 已验证

- 四页无控制台错误、无横向溢出；截图工具的默认可读性检查全部通过。
- 抽屉开门不遮状态列；单条剔除 / 撤销 / 恢复；批量选择 60 条并剔除（报「影响 32 个位点」）。
- 刷新后读回剔除状态与向导草稿（`_dms-ui/seed-*.html` 写入固定状态后重开验证）；`?reset=1` 清空。
- 导出 CSV、生成流程（向导第 4 步 → 生成 → 落到结果页）。

## 已知限制

- 只有 TEM-1 有真实变体表，其余五个文库是「尚未生成结果」的空状态。
- 下单是本地提示，没有后端；「合成性」是规则算出的启发式分数，不是合成商模型。
- 「预估覆盖」是展示值，不是仿真结果。
- 批量剔除没有二次确认（靠撤销兜底），全选只覆盖当前页 60 条。
