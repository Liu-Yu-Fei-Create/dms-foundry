# 软件著作权登记材料

面向中国版权保护中心（CPCC）的计算机软件著作权登记。所有材料基于本仓库当前代码与文档生成。

## 需要提交的材料

| 材料 | 要求 | 本目录对应 |
| --- | --- | --- |
| 申请表 | 在线填写（register.ccopyright.com.cn） | `application-info.md` 提供逐项参考 |
| 源程序 | 前 30 页 + 后 30 页，每页 ≥50 行；页眉含软件名称与版本；连续页码 | `make_docs.py` 生成 `out/DMS-Foundry-源代码.docx` |
| 文档 | 60 页（前 30 + 后 30），页眉同源程序 | `make_docs.py` 生成 `out/DMS-Foundry-用户手册.docx` |
| 身份证明 | 个人：身份证正反面；公司：营业执照副本 | 需自行准备 |
| 权利归属证明 | 委托/合作开发、职务作品时提供 | 视情况 |

> 生成的是 `.docx`：用 WPS/Word 打开后「另存为 PDF」再上传（CPCC 要求 PDF）。

## 开源与软著的关系

软著登记是**声明性**的，不要求代码保密；已在 GitHub 公开不影响登记。但注意：

1. **申请人必须与著作权人一致**：个人申请 vs 公司申请，取决于开发时的身份与劳动/委托合同；
2. **MIT 许可不改变著作权归属**，只是授权他人使用；
3. 若后续有公司主体，建议以公司名义申请，并把 GitHub 组织迁移过去，避免权利人与公开主体不一致。

## 时间线

- 官方登记免费；正常审查约 30–60 个工作日，可付费加急；
- 受理后可在 CPCC 官网查询进度；
- 证书下来后可把登记号写进 README 与 Release 说明。
